### 📖 Overview

This mini-project highlights the process of transforming a program initially written in **C** into a more intricate low-level language: **assembly**.  
Here I employed the **MIPS ISA** to accomplish this conversion, offering a glimpse into the fusion of high-level coding and low-level intricacy.
